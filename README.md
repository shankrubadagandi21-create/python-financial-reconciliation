# Financial Transaction Reconciliation and Exception Reporting

## Project Overview
This project automates financial transaction reconciliation by comparing internal payment records with bank transaction statements using Python.

## Business Problem
Manually comparing thousands of financial transactions is time-consuming and can lead to errors.

This project identifies matching transactions, missing transactions, duplicate records and amount discrepancies.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Datetime
- OpenPyXL
- CSV
- Google Colab

## Project Workflow
1. Load internal and bank datasets.
2. Inspect and understand the data.
3. Perform data cleaning.
4. Identify missing and invalid records.
5. Detect duplicate transactions.
6. Match transactions using Transaction ID.
7. Classify reconciliation results.
8. Calculate amount differences.
9. Generate exception reports.
10. Export CSV and Excel reports.

## Reconciliation Categories
- Matched
- Missing in Bank
- Missing Internally
- Amount Mismatch
- Date Mismatch
- Amount & Date Mismatch

## Project Deliverables
- Clean Internal Payments
- Clean Bank Transactions
- Duplicate Transaction Reports
- Full Reconciliation Report
- Matched Transactions Report
- Exception Report
- Reconciliation Summary
- Excel Reconciliation Report

## Business Benefits
- Reduces manual work.
- Improves transaction accuracy.
- Identifies financial discrepancies.
- Supports finance team investigations.
- Automates reporting.

## Conclusion
Developed an automated financial transaction reconciliation workflow using Python, Pandas and NumPy.
